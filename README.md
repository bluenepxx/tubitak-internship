# TUBITAK Internship

This repository contains my work during my internship in the Artificial Intelligence and Sensor Systems unit.

## Current Project

Exploration and machine learning studies using the QMOF dataset.

## Goals

- Understand the QMOF dataset
- Perform exploratory data analysis
- Study material properties
- Build baseline machine learning models
- Explore structure-based material property prediction

## Project Structure

- `data/` - Local dataset files
- `notebooks/` - Data analysis and experiments
- `src/` - Python source code
- `results/` - Generated plots and experiment results
